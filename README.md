# Echoes Of The Orion

Single-page band site for Echoes Of The Orion, built with Vite, React, TypeScript, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Local dev URL:

```text
http://127.0.0.1:4173/EotoWebsie/
```

## Build

```bash
npm run build
```
